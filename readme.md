\# Full-Stack To-Do App



\## Architecture

\- \*\*Frontend\*\*: Next.js (React)

\- \*\*Backend / API\*\*: Next.js Route Handlers

\- \*\*Database\*\*: SQLite (better-sqlite3)

\- \*\*Security\*\*: Passwords hashed using bcryptjs



\## Production Note

\*Note: SQLite is used here for demonstration purposes. In a real production deployment on a serverless platform like Vercel, a hosted database (such as Supabase, Neon, or PlanetScale) must be used instead, as serverless environments do not persist local file system writes.\*
